<objective>
Close **CR-02** — the windowed body scan is not equivalent to whole-document processing, so a secret the
single-pass path redacts survives the windowed path.

`windowEnd`'s own comment states the hazard exactly: `jsonSecretKeyRegex`'s whitespace class can span
newlines, so a pretty-printed key/colon/value pair split across a window boundary would be missed. It
then mitigates by pulling in **exactly one** additional line and never re-checking, so the very shape the
comment cites is unhandled. When the key, the colon and the value sit on three lines, the boundary lands
after the key line, the check fires, the colon line is pulled in, and the window stops there — the value
starts the next window and the rule cannot match across the cut. Reproduced by the reviewer at
`shift=7`: `windowedLeak=true singlePassLeak=false`. Response bodies are attacker-controlled and window
boundaries are deterministic given a known prefix length, so the alignment is craftable.

Two things follow, and this plan does both. The **code** must loop the extension under a hard cap. The
**records** must stop claiming what does not ship: `Redaction.kt:429-431` asserts line-boundary cutting
was "proven byte-identical to whole-document processing", `.planning/codebase/CONCERNS.md` asserts "the
built-in rules are unaffected ... the `windowEnd` JSON boundary-safety rule covers `jsonSecretKeyRegex`",
and ADR-14's residual bullet attributes boundary misses to **user** patterns only. All three were false
as shipped. D-08 REFINED is the governing precedent: an ADR claims only what ships, which is exactly why
ADR-14 says "body stage" rather than making the unqualified claim — the same discipline applies here.

**WR-06 is folded in** rather than deferred, because it is not an adjacent nicety: it is the precise test
gap CR-02 fell through. Nothing in the committed suite asserts the D-01 invariant, and a shifted-fixture
sweep found a counterexample within eight shifts.

Purpose: PRIV-06, CR-02, WR-06, D-01 AMENDED, D-08 REFINED.
Output: a looping, capped boundary extension; the sweep test D-01 always claimed; three corrected records.
</objective>
