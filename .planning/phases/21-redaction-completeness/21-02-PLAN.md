<objective>
Build the two primitives the PRIV-06 body-stage rewrite (plan 21-06) depends on, in files that no other
wave-1 plan touches.

`SafeRegex.replaceAllSafe` returns the **original input unchanged** on timeout — documented as
fail-open, and asserted as such by `SafeRegexTest.kt:44`. The return value is therefore
indistinguishable from "the pattern matched nothing". A body stage built naively on it would be
fail-**open** in exactly the case D-02 exists to close, while looking correct. D-14 adds a reporting
sibling so the body stage can drop an unscanned window instead of passing it through.

Purpose: PRIV-06 / D-14 (make timeout observable), PRIV-06 / D-04 (window width and total budget as
constants, with the KDoc that today documents the fail-open being fixed).
Output: `SafeRegex.replaceAllSafeReporting` + `SafeReplaceResult`, `Defaults.MAX_REDACTION_BUDGET_MS`,
a corrected `MAX_REDACTION_BODY_CHARS` KDoc, and `timedOut` test coverage.
</objective>

| Boundary | Description |
|----------|-------------|
| caller-supplied string → regex engine | `Redaction.apply` is reachable with caller-sized input from MCP tools (`redact_preview`, `McpToolContext.redactIfNeeded`) and from the passive scanner; unbounded regex work on that input is a resource-exhaustion vector |
| user-supplied custom regex → regex engine | Custom redaction patterns are user input compiled into `Pattern`s and executed against attacker-influenced text |
