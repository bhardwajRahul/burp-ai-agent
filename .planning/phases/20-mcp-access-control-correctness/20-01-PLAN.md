<objective>
Build the two pure, server-free halves of the MCP access-control gate: the decision core that
says allow-or-deny, and the blocked-request reporter that turns a denial into observability.

Neither file touches Ktor. Both are directly unit-testable without binding a port, which is what
makes the Wave 2 plugin a thin adapter instead of a second place where security logic lives.

Purpose: SEC-04 requires the checks to run before any handler; SEC-05 requires the predicates
those checks call to be correct (bracketed IPv6, blank token). Extracting them into a pure module
also keeps `KtorMcpServerManager.start`'s module lambda under detekt's `LongMethod` threshold of 80
and keeps `ReturnCount` (baseline offender #2, 133 entries) from growing — QUAL-07 forbids growing
`detekt-baseline.xml` (currently 1096 entries).

Output: `McpAccessControlDecision.kt`, `McpBlockedRequestReporter.kt`, and their two unit test classes.
</objective>

   SINGLE expression body: `= if (settings.externalEnabled) evaluateExternal(facts, settings) else evaluateLocal(facts, settings)`.
   `evaluateExternal` and `evaluateLocal` are `private fun`s, each a single `when { ... }` EXPRESSION

   comment it as D-01), then blank-token (`settings.token.isBlank()` -> `Deny(HttpStatusCode.Unauthorized, BlockReason.BLANK_TOKEN, facts)`),
   then bearer (`!isAuthorizedBearer(facts.authorization.orEmpty(), settings.token)` ->
   `Deny(HttpStatusCode.Unauthorized, BlockReason.UNAUTHORIZED, facts)`), else `GateDecision.Allow`.

   `evaluateLocal` branch order:
   Origin present and not loopback -> `Deny(HttpStatusCode.Forbidden, ORIGIN_MISMATCH, facts)`;
   Origin ABSENT and `isBrowserUserAgent(facts.userAgent)` -> `Deny(Forbidden, BROWSER_NO_ORIGIN, facts)`;
   Host present and not a valid authority for `settings.port` -> `Deny(Forbidden, HOST_MISMATCH, facts)`;

   it in a code comment above that branch. This branch NARROWS the browser-UA denial to the

   - `private fun parseAuthority(value: String): Pair<String, Int?>?` — the ONE place that parses an
     authority. Returns `host to port`, with a null port when none was present, or `null` when the
     input is malformed.

     SHAPE CONSTRAINT, load-bearing: this function has a budget of AT MOST TWO `return` keywords.
     `detekt.yml` overrides only `LongMethod`, `LongParameterList`, `MaxLineLength` and
     `FunctionNaming`, so `ReturnCount` runs at its default max of 2. The five-step imperative parse
     this replaces would naturally be five or six `return`s and would fail the very `detekt` gate this
     plan must keep green, and QUAL-07 forbids adding a `detekt-baseline.xml` entry to work around it.

     Write it as: `val trimmed = value.trim().lowercase()`, one guard `if (trimmed.isEmpty()) return null`,
     then a single `when` EXPRESSION whose value is the returned pair, branches in this order:
       * `trimmed in BARE_IPV6_LOOPBACKS` -> `trimmed to null`. This membership check comes FIRST, before
         the multi-colon rejection below, so a bare `::1` with no port is accepted.
       * `trimmed.startsWith("[")` -> the literal runs to the first `]`; the brackets are stripped;
         whatever follows `]` must be either empty (port null) or `":"` followed by digits (port parsed
         with `toIntOrNull()`); anything else makes the branch yield `null`. A missing `]` yields `null`.
       * `trimmed.count { it == ':' } > 1` -> `null`. A valid non-IPv6 authority has at most one `:`, so
         more than one at this point means an unbracketed or malformed IPv6 literal.
       * `else` -> split on the single `:` when present; `toIntOrNull()` on the port half, and a
         non-numeric port yields `null`.

     neither a `return` nor an exception handler.

   - `isValidHostAuthority(host: String, expectedPort: Int): Boolean` = `isLoopbackAuthority(host, expectedPort)`.
