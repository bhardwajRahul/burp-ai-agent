<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Burp Preferences / settings import → CLI argv | A CLI command, its extras and the agent profile are user- or import-supplied strings that become process arguments. |
| CLI argv → `sh -c` (PTY path only) | On the `usePty` + Unix branch the argv is joined into ONE shell command string, so every argument is re-parsed by `/bin/sh`. This is the only place in the file where argument boundaries are re-derived by a shell. |
| CLI child stdout → extension | Output is read back and rendered; ANSI sequences are stripped. Not a new boundary in this plan. |
