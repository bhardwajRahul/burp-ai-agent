## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Burp local data (proxy history, site map, cookie jar, Burp options) → AI backend | The tier table decides which local data can flow to a third-party model with no human in the loop. This is the data-protection control, not decoration. |
| Model output → tool selection | The model chooses which tool runs; its context contains attacker-controlled data, so the choice is attacker-influenceable. |
