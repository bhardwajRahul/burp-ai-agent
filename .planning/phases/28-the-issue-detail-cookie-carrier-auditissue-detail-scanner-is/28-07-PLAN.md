<the_choice_this_plan_makes>
**Item 5 of the round-3 contract offers two options. This plan takes NAME THE RESIDUAL, and the
reason is stated here so no reader has to infer it.**

Route 1's gate is safe by construction: `InjectionType`'s only cookie-capable member IS `COOKIE`, so
D-28-01's pass-through for every other member cannot fail open on a cookie. Montoya's
`AuditInsertionPointType` is not like that. Four of its members can carry a cookie value while not
being `PARAM_COOKIE`: `HEADER` (a `Cookie:` request header presented as a header insertion point),
`USER_PROVIDED`, `EXTENSION_PROVIDED` (which is also what `type()`'s default body returns), and
`UNKNOWN`. For those the route-2 gate is fail-OPEN today.

**Widening the predicate to that set was considered and NOT taken, for four reasons:**

1. It would strip `**Original Value:**` on EVERY header-typed, user-provided, extension-provided and
   unknown insertion point — removing the operator's own value from every non-cookie header finding.
   That is a product behaviour change, not a record repair, and nobody has asked for it.
2. It contradicts D-28-01's deliberate pass-through discipline for non-cookie types, which route 2
   copied on purpose so a reader meets one control applied twice rather than two mechanisms.
3. It would move `CookieRouteDispositionTest`'s two pinned predicate populations, which are evidence
   for a different claim, and it would need its own red probe and its own reachability measurement —
   the very thing plan 27-08's TRANSFER disposition exists to insist on.
4. This round is chartered as record repair. Shipping a behaviour change inside it would leave the
   register describing code that no longer exists, in the opposite direction from the drift the
   round is fixing.

So the residual is NAMED: at `isCookieInsertionPoint`'s KDoc, pinned by
`theRouteTwoGateIsFailOpenForTheseCookieCapableTypes`, bounded by
`theInsertionPointTypeEnumPopulationIsTheOneTheResidualWasMeasuredAgainst`, and carried into the
archival record by plan 28-08. A named residual with a red tripwire is worth more than a silent
widening; an unnamed fail-open set is what D-28-11 called out.
</the_choice_this_plan_makes>
